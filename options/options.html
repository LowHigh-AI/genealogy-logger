How to Log Records

⌨️
Omnibox Quick Log

Type log then press Space or Tab in Chrome's address bar, type any optional notes, and press Enter.

🖱️
Toolbar Click

Click the 📜 extension icon in your Chrome toolbar on any genealogy page to log instantly.

⚡
Keyboard Shortcut

Press Ctrl+Shift+L (or ⌘+Shift+L on Mac) to trigger extraction instantly.

🌐
Specialized Sites

FamilySearch, MyHeritage, GenealogyBank, Find A Grave, Chronicling America (LOC), National Archives (NARA), BLM Land Records, Internet Archive, WikiTree, BillionGraves, plus any page with highlighted text.

Google Sheet Webhook Setup (2 Minutes)

  1. Open your target Google Sheet.
  2. Click Extensions > Apps Script in the Google Sheets top menu.
  3. Replace existing code with the companion script ().
  4. Click Deploy > New deployment.
  5. Choose type Web app. Set Execute as: "Me" and Who has access: "Anyone".
  6. Click Deploy and paste the generated Web app URL into the field above.
