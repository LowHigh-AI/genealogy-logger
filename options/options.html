Google Sheet Webhook Setup

  1. Deploy the provided Code.gs to your Google Apps Script project.
  2. In your GAS project settings, add the GEMINI_API_KEY script property with your Gemini API key.
  3. Add the GAS_SECRET_KEY script property with a secure password (e.g., GENEALOGY_SECRET_2026).
  4. Deploy as a Web App and paste the URL and Secret Key above.
